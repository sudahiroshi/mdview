mdview — インストール手順
==========================

1. 左の mdview を、右の「アプリケーション」フォルダへドラッグしてください。


2. アプリケーションフォルダの mdview をダブルクリックすれば起動します。

   初回だけ「インターネットからダウンロードされたアプリケーションです。
   開いてもよろしいですか？」と確認が出ます。「開く」を押してください。

   このアプリは Apple の署名と公証を受けています。
   特別な許可操作は要りません。


3. 使い方

   Markdown ファイルをウインドウにドラッグするか、⌘O で開きます。
   図（Mermaid / Graphviz / PlantUML）と数式が描画され、
   図や表を PDF・PNG・SVG・LaTeX に書き出せます。
   文書全体を PDF にするには ⌘P です。
   ⌘N で新しいウインドウを開けるので、複数の文書を並べて読めます。


4. 動作環境

   macOS 11 以降。Apple Silicon と Intel の両方で動きます。
   Java や Graphviz などの追加インストールは要りません。
   図の内容が外部に送信されることはありません。
