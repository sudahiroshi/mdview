# mdview

Markdown を「読む・見せる・部品を取り出す」ためのビューアー。

- Mermaid / Graphviz / PlantUML / 数式を描画して閲覧する
- 図や数式を **PDF・PNG・SVG** で単体書き出しする
- 表を **LaTeX（booktabs）** に変換してコピー・保存する
- 表示モード切替で **章・節・項の番号、図表番号、相互参照** を自動で付ける
- 文書全体を、文書名とページ番号付きの **PDF** にする

編集機能はありません。`.md` は普段のエディタで編集し、本アプリは保存を検知して描き直します。

外部コマンドは一切使いません。図も数式も同梱の JavaScript と WebAssembly だけで描くので、
**図の内容が外部サーバへ送られることはありません。**

---

## 2 つの使い方

| | デスクトップ版 | ブラウザ版（PWA） |
|---|---|---|
| 形 | macOS アプリ（`.app`） | Chrome / Edge で開く |
| 向き | いつも使うなら | 他の端末でも使いたいとき |
| PDF | ボタン一発で保存 | 印刷ダイアログを経由 |

作り方は [開発者向けドキュメント](DEVELOPMENT.md) を参照してください。

**デスクトップ版**は `dist/mac-arm64/mdview.app` を起動します。未署名なので、
初回だけ **右クリック → 開く** が必要な場合があります。

**ブラウザ版**は `npm run web:serve` で <http://localhost:4174/> を開きます。
Chrome のアドレスバー右のインストールボタンから入れると、独立したウインドウで動きます。
一度開けばオフラインでも起動します。

## 記法

番号付けと相互参照の記法は [pandoc-crossref](https://lierdakil.github.io/pandoc-crossref/) に合わせてあります。
素の Markdown としても読めるので、他のツールに持ち出しても壊れません。

````markdown
## はじめに {#sec:intro}

![システム構成](fig/arch.png){#fig:arch}

```mermaid {#fig:flow caption="処理フロー"}
graph TD; A --> B;
```

: 実験条件 {#tbl:cond}

| 項目 | 値 |
|:-----|---:|
| N    | 10 |

詳細は [@sec:intro]、構成は [@fig:arch]、条件は [@tbl:cond] を参照。
````

| 対象 | id の書き方 | キャプション |
|---|---|---|
| 見出し | `## 見出し {#sec:x}` | — |
| 画像 | `![代替テキスト](a.png){#fig:x}` | 代替テキストがそのままキャプションになる |
| 図式フェンス | 情報文字列に `{#fig:x caption="..."}` | `caption=` で指定 |
| 表 | キャプション行に `{#tbl:x}` | 表の直前か直後の `: キャプション` 行 |

- 図式フェンスの言語は `mermaid` / `dot`（`graphviz`, `neato`）/ `plantuml`（`puml`, `uml`）です。
- 画像だけを含む段落は図として扱われます。
- 数式は `$...$`（本文中）と `$$...$$`（独立行）。`$$...$$ (1)` で式番号を添えられます。
- 参照先が見つからない `[@fig:x]` は `[?fig:x]` と赤字で表示されます。

## 表示モード

ツールバーで切り替えます。選択は保存されます。

**番号**

| モード | 内容 |
|---|---|
| なし | 番号を付けない。参照は見出し・キャプションの文言へのリンクになる |
| 見出しのみ | 章・節・項だけに番号を付ける |
| 見出し + 図表 | 図表番号と相互参照も解決する（既定） |

**様式**

| | 章 | 節 | 図 | 表 | 節への参照 |
|---|---|---|---|---|---|
| 和文 | 第1章 | 1.1 | 図 1.1 | 表 1.1 | 1.1 節 |
| 英文 | Chapter 1 | 1.1 | Figure 1.1 | Table 1.1 | Section 1.1 |

### 章の決まり方

- **冒頭の H1 が文書中に 1 つだけなら、それは文書タイトルとみなして番号を付けません。**
  その下の H2 を章として数えます（`# 論文題目` → `## 序論` を「第1章 序論」にするため）。
- H1 が複数あれば H1 が章です。
- H1 が無ければ章という概念を置かず、最上位の見出しを 1 から数えます。

図表番号は章ごとに振り直します（図 1.1, 図 1.2, 図 2.1 …）。ただし次の場合は
**文書全体を通し番号**（図 1, 図 2 …）にします。

- H1 が無い文書
- 最初の章より前に図表がある文書（「図 1」と「図 1.1」が混ざるのを避けるため）

本文側ですでに手で番号を振ってある文書（`## 1.1 目的` など）は二重になるので、
番号モードを「なし」にして読んでください。

## 書き出し

### 図・数式・表（要素ごと）

図や数式、表にカーソルを重ねると右上にボタンが出ます。

| 対象 | 形式 | 備考 |
|---|---|---|
| 図・数式 | PNG | 等倍〜12 倍。書き出される実ピクセル数を見ながら選べる |
| 図・数式 | PDF | 実寸ちょうどの 1 ページ。日本語もベクターのまま |
| 図・数式 | SVG | 再編集用 |
| 数式 | LaTeX | TeX の原文をクリップボードへ |
| 表 | LaTeX | booktabs の `table` / `longtable`。コピーまたは `.tex` 保存 |

- 書き出しボタンが出るのは **独立行の数式（`$$...$$`）だけ**です。本文中の `$...$` には出ません。
- 数式は元が小さいので、PNG は 8〜12 倍が使いやすいです。PDF と SVG はベクターなので倍率は関係ありません。
- PNG の倍率メニューでは、大きすぎて扱えなくなる倍率（8192px 超、または 4000 万画素超）は出ません。
- 表の LaTeX は `\usepackage{booktabs}` が要ります（出力の先頭にコメントで記載されます）。
  列揃え・TeX 特殊文字の退避・インラインコード（`\texttt`）・強調（`\textbf` / `\emph`）・
  数式の素通しに対応しています。

### 背景（白 / 透過）

書き出しバーの一番右の **背景:白 / 背景:透過** で切り替えます。設定は保存され、
**PNG と SVG** に効きます。透過を選ぶと、Graphviz が図に敷いている白い下地も一緒に外れます。

**PDF は常に白背景です。** Chromium の書き出しがページ全面を必ず塗るためで、
こちらから消す手立てがありません。透過が要るときは SVG か PNG を使ってください。

### 文書全体（PDF）

ツールバーの **PDF…**、またはメニューの「ファイル > 文書全体を PDF に書き出し…」（<kbd>⌘P</kbd>）。

| 項目 | 選べるもの |
|---|---|
| 文書名 | 任意の文字列（既定はタイトル見出し、無ければファイル名） |
| 文書名の位置 | 表示しない / ページ上部 / ページ下部 |
| 文書名の揃え | 左 / 中央 / 右 |
| ページ番号の位置 | 表示しない / ページ上部 / ページ下部 |
| ページ番号の揃え | 左 / 中央 / 右 |
| 総ページ数 | 添える（`3 / 12`）か、番号だけか |
| 用紙 | A4 / A5 / B5 / Letter / Legal |
| 余白 | mm 指定（ヘッダー・フッターはこの余白の中に入る） |

用紙・余白・位置・揃えは保存されます。文書名だけは文書ごとに変わるので保存しません。

ページ送りの扱い:

- 図・数式・コードブロックはページの途中で分割しません。見出しだけがページ末尾に取り残されることもありません。
- 表は行の境界でなら分割し、またいだ先では見出し行を繰り返します。
- 用紙に収まらない大きな図は、収まるところまで縮めます。

## ブラウザ版の違い

| | デスクトップ版 | ブラウザ版 |
|---|---|---|
| ファイルを開く | ダイアログ / ドロップ / Finder から | ダイアログ / ドロップ |
| 相対パスの画像 | 文書と同じフォルダの中なら読める | **画像のあるフォルダを一度許可する**（案内が出ます） |
| 保存を検知して再描画 | OS の通知 | 0.8 秒ごとの確認（ダイアログで開いた場合のみ） |
| 最近使った文書 | メニューにあり | なし |
| PNG / SVG の保存 | 保存先を選ぶ | 保存先を選ぶ |
| PDF | ボタン一発で保存 | **印刷ダイアログで送り先に「PDF に保存」を選ぶ** |

**印刷ダイアログの「ヘッダーとフッター」は、入れても切っても出力は変わりません。**
アプリ側が全部の辺を押さえているので、ブラウザ既定の日付・タイトル・URL は出ません。

**対応ブラウザは Chrome / Edge です。** Safari と Firefox はローカルファイルを扱う API を
実装していないため、ファイル選択は通常のファイル選択に、保存はダウンロードに落ちます。
相対パスの画像と自動リロードは使えません。その場合は画面にその旨を表示します。

## 困ったとき

**図が「描画中…」のまま / エラーが出る**
図式の構文エラーです。その図の位置にエラー内容が出るので、記法を直してください。
他の図の描画は止まりません。

**画像が出ない**
表示できる画像には範囲があります。読めなかった画像はその場に理由付きの枠が出て、
本文の上にも案内が出ます。

- **デスクトップ版**: 文書と同じフォルダの中にある画像だけを表示します。
  `../images/a.png` のように**上の階層にある画像は表示しません**。
- **ブラウザ版**: 案内の「フォルダを許可…」から、画像のあるフォルダを選んでください。
  許可したフォルダの中だけが読めます。
- **どちらも外部 URL の画像（`https://...`）は表示しません。**

**保存しても画面が変わらない**
デスクトップ版はファイルのあるフォルダを監視しています。別のフォルダへ書き出す
エディタでは検知できないことがあります。<kbd>⌘R</kbd> で読み直してください。

**PDF の数式や図がぼやける**
ぼやけません。書き出した PDF はすべてベクターです。閲覧ソフトの表示倍率の問題です。

**番号が二重に出る**
本文側にすでに番号が書かれています。番号モードを「なし」にしてください。

## 既知の制限

- **PDF の背景は透過にできません**（Chromium の制約）。SVG か PNG を使ってください。
- **表示できる画像は、文書と同じフォルダ（ブラウザ版は許可したフォルダ）の中だけ**です。
  上の階層の画像と外部 URL の画像は表示しません。
- **PlantUML の標準ライブラリ**（`!include <C4/C4_Context>` など）は同梱していません。
- デスクトップ版は未署名・未公証です。他の人に配るには Apple の署名が必要です。
- ブラウザ版に「最近使った文書」はありません。
- 式番号（`$$...$$ (1)`）は表示するだけで、`[@eq:x]` のような相互参照には対応していません。
